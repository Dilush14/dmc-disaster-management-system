# DMC frontend
The mobile public portal is available at `/public`. See [public portal documentation](PUBLIC_PORTAL.md) for routes, authentication, API contracts and validation. Existing welcome/staff authentication routes remain at `/` and `/auth` and share the blue system theme.
See [project README](../README.md) for configuration, scope and placeholders.
Run `npm install`, then `npm run dev`. Check with `npm run build`, `npm test` and `npm run test:e2e`.
